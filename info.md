# Sonos Unified

Unify Sonos S1 and S2 speakers into a single synchronized HA media player, with millisecond acoustic calibration via your phone microphone.

**Features:**
- Single virtual media player entity bridging S1 + S2 generations
- Acoustic auto-calibration via Web Audio API (no extra hardware)
- Manual delay slider and HA Options flow
- Standard HA grouping (`media_player.join` / `unjoin`)
- Does not modify the core Sonos integration
